What is this?

why post-quantum

the map doesn't need crypto. the command does. a forged or replayed command to a lunar asset is catastrophic, and the link lives for decades: the adversary records today and breaks it with a quantum computer later. every command carries an ML-DSA (FIPS 204) signature, verified on the device. the post-quantum signing key never leaves the phone.
measured in the spike: ML-DSA-65, signature 3309 B, sign ~29 ms, verify ~5 ms.
